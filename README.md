## Como enviar arquivos pelo celular

Você pode enviar arquivos para este repositório diretamente pelo celular de duas formas:

---

### Opção 1 — Pelo aplicativo GitHub (recomendado)

1. Baixe o aplicativo **GitHub** na [App Store (iPhone)](https://apps.apple.com/br/app/github/id1477376905) ou no [Google Play (Android)](https://play.google.com/store/apps/details?id=com.github.android).
2. Faça login com a sua conta do GitHub.
3. Abra este repositório: **Erikfy577/trabalhos.py**
4. Navegue até a pasta onde deseja adicionar o arquivo.
5. Toque no ícone **"+"** ou em **"Adicionar arquivo"**.
6. Escolha **"Fazer upload de arquivos"** e selecione o arquivo do seu celular.
7. Adicione uma mensagem de commit descrevendo o que foi enviado.
8. Toque em **"Commit"** para confirmar o envio.

---

### Opção 2 — Pelo navegador do celular

1. Abra o navegador do seu celular (Chrome, Safari, etc.).
2. Acesse [github.com](https://github.com) e faça login.
3. Vá até o repositório **Erikfy577/trabalhos.py**.
4. Clique em **"Add file"** → **"Upload files"**.
5. Arraste ou selecione o(s) arquivo(s) do seu dispositivo.
6. Preencha a mensagem de commit e clique em **"Commit changes"**.

---

### Dica

Se você quer **criar um novo arquivo** diretamente pelo celular (sem precisar do computador), escolha a opção **"Create new file"** em vez de "Upload files". Você poderá escrever o código diretamente no editor do GitHub.
